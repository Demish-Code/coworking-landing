# Coworking Landing Page (CoWo)

Адаптивная посадочная страница для коворкинг-пространства, сверстанная по дизайн-макету из Figma.

🔗 **[Открыть живую версию сайта (Live Demo)](https://demish-code.github.io/coworking-landing/)**

## О проекте
В рамках работы реализован полный цикл верстки лендинга с нуля с упором на чистую структуру кода и плавность интерфейса:
* **Семантическая разметка (HTML5):** логическое разделение на секции (`header`, `overview`, `features`, `focused`, `contact`, `footer`).
* **Методология БЭМ:** понятное и масштабируемое именование классов без конфликтов стилей.
* **Гибкая сетка (CSS3 Flexbox):** выравнивание колонок, карточек преимуществ и формы обратной связи.
* **Интерактив и типографика:** подключены веб-шрифты Google Fonts (`Lato`), настроена плавная якорная прокрутка (`scroll-behavior: smooth`) и мягкие `:hover`-эффекты на кнопках и ссылках.

## Технологический стек
* HTML5
* CSS3 (Flexbox)
* Методология БЭМ
* Git / GitHub Pages
